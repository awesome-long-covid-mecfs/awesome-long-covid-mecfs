# Mitmachen

Du kennst eine Quelle, die hier fehlt? Es gibt drei Wege, sie uns zu schicken – wähle einfach den, der zu dir passt. Jeden Vorschlag prüft ein Mensch.

## Option 1: Per E-Mail (ohne GitHub-Konto)

Schreib an `awesome-long-covid-mecfs[at]sags-per-mail.de` (`[at]` bitte durch `@` ersetzen). Die Adresse ist so geschrieben, damit einfache Spam-Crawler sie nicht absammeln.

Bitte nenne:

- Name der Quelle
- Link
- Sprache
- Kategorie
- Quellentyp (Studie, Leitlinie, Selbsthilfe, …)
- ein kurzer Grund

## Option 2: GitHub-Issue (mit Konto)

1. Auf der GitHub-Seite **Issues** öffnen.
2. **New issue** → Vorlage **„Suggest a link"** wählen.
3. Felder ausfüllen: Name, Link, Sprache, Kategorie, Quellentyp, kurzer Grund.
4. Absenden. Ein Mensch prüft den Vorschlag und nimmt ihn bei Passung auf.

Kaputter Link? Vorlage **„Broken link"** verwenden.

## Option 3: Pull Request (wenn du GitHub kennst)

1. Repo forken und einen Branch anlegen.
2. Nur **eine Änderung pro Pull Request**.
3. Eintrag in die passende `links-<sprache>.md` und Kategorie schreiben.
4. Format: `- **[Name](URL)** — Ein Satz. 📄 [Study]` (Icon + englischer Marker, kein Datum).
5. [MARKERS.md](MARKERS.md) und [AGENTS.md](AGENTS.md) beachten.
6. Kurz begründen, warum die Quelle aufgenommen werden sollte.

## Was wir nicht aufnehmen

Heilversprechen, Werbung, Affiliate-Links, Inhalte hinter Bezahlschranke ohne freie Zusammenfassung, Verschwörungsquellen, URL-Shortener, doppelte Einträge.
Details: [AGENTS.md](AGENTS.md), [Links (EN)](links-en.md) und die englische [Anleitung](CONTRIBUTING.md).

## Verhalten

Bitte respektvoll bleiben – der [Code of Conduct](CODE_OF_CONDUCT.md) gilt für Issues, Pull Requests und alle Diskussionen.
