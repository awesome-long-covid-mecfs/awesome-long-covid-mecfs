# Awesome Long COVID & ME/CFS

Curated resources on **Long COVID / Post-COVID**, **ME/CFS (Myalgic Encephalomyelitis / Chronic Fatigue Syndrome)**, POTS, MCAS, hEDS, fibromyalgia, SIBO, dysautonomia and other post-viral conditions – with a focus on fatigue, PEM and symptom management.

For **patients, carers and researchers**. This list is multilingual: resources appear in the language in which they were published. Every entry is checked by a human before it goes live.

> **Important:** This list is **not medical advice**, not a substitute for doctors or therapists, and not a recommendation for any treatment. We only link to sources – their publishers are responsible for their content.

## What this list is about

- Orientation: reliable places instead of scattered search results
- Research: studies, guidelines and specialist information
- Daily life: self-help, care, assistive devices, legal matters and benefits
- Explicitly **no** miracle cures, conspiracy sources or advertising

## Contributing

<details markdown="block">
<summary>Show how to contribute</summary>

Know a good source that is missing? You do not need Git or GitHub:
[Open the "Add a link" issue](https://github.com/awesome-long-covid-mecfs/awesome-long-covid-mecfs/issues/new?template=add-resource.yml).
Found a dead link? Use ["Broken link"](https://github.com/awesome-long-covid-mecfs/awesome-long-covid-mecfs/issues/new?template=broken-link.yml).

If you know GitHub, you can also send a pull request – please follow [CONTRIBUTING.md](CONTRIBUTING.md) and [AGENTS.md](AGENTS.md).

**Without a GitHub account:** email `awesome-long-covid-mecfs[at]sags-per-mail.de` (replace `[at]` with `@`). The address is written this way so simple spam crawlers cannot collect it.

</details>

## Legend

All markers are listed in [`MARKERS.md`](MARKERS.md) – the single source of truth, with the German translation of each marker name. The icon is **always followed by the English text marker**, e.g. `📄 [Study]`, so screen readers can read it.

We do **not** rate sources with stars or "good/bad" labels – we name the type of source so readers can judge for themselves. Several markers can be combined on one entry.

The detailed admission rules are in [AGENTS.md](AGENTS.md).
