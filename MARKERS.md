# Markers / Marker

This file is the **single source of truth** for all markers used in the resource lists. `links-en.md`, `links-de.md`, `AGENTS.md`, the issue templates and all entries refer to this file.

Diese Datei ist die **einzige Quelle** für alle Marker in den Ressourcenlisten. `links-en.md`, `links-de.md`, `AGENTS.md`, Issue-Formulare und alle Einträge verweisen darauf.

## Marker list

| Icon | Marker (EN) | Deutsch | Meaning / Bedeutung |
| --- | --- | --- | --- |
| 🏛️ | `[Authority]` | Behörde | Official body (e.g. RKI, WHO, NIH) |
| 📊 | `[Systematic review]` | Systematische Übersicht | Meta-analysis or review |
| 📄 | `[Study]` | Studie | Single scientific publication |
| 📋 | `[Guideline]` | Leitlinie | Recommendation by a professional body |
| 🤝 | `[Self-help]` | Selbsthilfe | Patient organisation or community |
| 💬 | `[Patient story]` | Erfahrungsbericht | Personal experience – not scientific evidence |
| 📖 | `[Professional literature]` | Fachliteratur | Textbook or professional literature |
| 📌 | `[Preprint]` | Preprint | Not peer-reviewed yet |
| 💰 | `[Commercial]` | Kommerziell | Commercial offer, mentioned neutrally |
| ⚠️ | `[Outdated]` | Veraltet | Historically interesting, no longer current |
| 🗂️ | `[Collection]` | Sammlung | Curated collection of links or studies |
| 🧰 | `[Tool]` | Werkzeug | App or web tool |
| 📣 | `[Advocacy]` | Advocacy | Political or advocacy work |

## Rules

- The icon is **always written together with the text marker**, e.g. `📄 [Study]`. Never the emoji alone – screen readers need the text.
- Several markers can be combined on one entry, e.g. `⚠️ [Patient story] 💰 [Commercial]`.
- If a certain combination occurs often, a new category may be created – agree with the user first.
- No stars and no "good/bad" ratings. Markers name the **type** of source; readers judge for themselves.
- New markers are added here first, then referenced everywhere else.
