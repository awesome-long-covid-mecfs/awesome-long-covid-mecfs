# Contributing

Found a source that belongs here? There are three ways to send it. Pick the one that suits you – a person reviews every suggestion.

## Option 1: By email (no GitHub needed)

Write to `awesome-long-covid-mecfs[at]sags-per-mail.de` (replace `[at]` with `@`). This spelling protects the address from simple spam crawlers.

Please include:

- name of the source
- link
- language
- category
- type of source (study, guideline, self-help, …)
- one short reason

## Option 2: GitHub issue (with an account)

1. Open **Issues** on the GitHub page.
2. **New issue** → choose **“Suggest a link”**.
3. Fill in the fields: name, link, language, category, type of source, short reason.
4. Submit. A person reviews it and adds it if it fits.

Found a dead link? Use the **“Broken link”** template.

## Option 3: Pull request (if you know GitHub)

1. Fork the repo and create a branch.
2. Only **one change per pull request**.
3. Add the entry to the correct `links-<language>.md` and category.
4. Format: `- **[Name](URL)** — One sentence. 📄 [Study]` (icon + English marker, no date).
5. Follow [MARKERS.md](MARKERS.md) and [AGENTS.md](AGENTS.md).
6. Briefly describe why the source should be included.

### Entry example

The sentence neutrally describes **what** the source is, **who** provides it, and **what is special** about it (access, language, scope):

```
- **[ME/CFS Research Foundation](https://mecfs-research.org/en/)** — Foundation of patients, relatives and supporters that funds biomedical research into ME/CFS and Long COVID and provides a research register, project overviews and information for patients. 🤝 [Self-help] 📣 [Advocacy]
```

## What we do not include

Miracle cures, advertising, affiliate links, paywall-only content, conspiracy sources, URL shorteners, duplicate entries.
Details: [AGENTS.md](AGENTS.md), [Links (DE)](links-de.md) and the German guide [CONTRIBUTING-de.md](CONTRIBUTING-de.md).
