# Mitmachen

Du musst **kein Programmierer** sein, um eine Quelle vorzuschlagen.

> **Kein GitHub-Konto?** Schreib uns einfach eine E-Mail an `awesome-long-covid-mecfs[at]sags-per-mail.de` – das `[at]` bitte durch `@` ersetzen. Die Schreibweise schützt die Adresse vor einfachen Spam-Crawlern.
> Bitte schicken: Name der Quelle, Link, Sprache, Kategorie, Art der Quelle und eine kurze Begründung.

## Variante 1: Issue öffnen (einfach)

1. Auf GitHub oben auf **Issues** klicken.
2. **New issue** → Vorlage **„Suggest a link"** auswählen.
3. Felder ausfüllen: Name, Link, Sprache, Kategorie, Art der Quelle, kurze Begründung.
4. Absenden. Eine Person prüft den Vorschlag und fügt ihn ggf. ein.

Kaputter Link? Vorlage **„Broken link"** benutzen.

## Variante 2: Pull Request (wenn du GitHub kennst)

1. Repo forken und einen Branch anlegen.
2. Nur **eine Änderung pro Pull Request**.
3. Eintrag in die passende `resources-<sprache>.md`, in die passende Kategorie.
4. Format einhalten: `- **[Name](URL)** — Ein Satz. 📄 [Study]` (Icon + englischer Marker, kein Datum).
5. [MARKERS.md](MARKERS.md) und [AGENTS.md](AGENTS.md) beachten.
6. Kurz beschreiben, warum die Quelle aufgenommen werden sollte.

## Was wir nicht aufnehmen

Heilversprechen, Werbung, Affiliate-Links, Paywall-only-Inhalte, Verschwörungsquellen, URL-Shortener, doppelte Einträge.
Details stehen in [AGENTS.md](AGENTS.md) und in der deutschen [README-de.md](README-de.md).

## Verhalten

Bitte respektvoll bleiben – die [Code of Conduct](CODE_OF_CONDUCT.md) gilt für Issues, Pull Requests und alle Diskussionen.
