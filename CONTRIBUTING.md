# Contributing

You do **not** need to be a programmer to suggest a source.

> **No GitHub account?** Just email us at `awesome-long-covid-mecfs[at]sags-per-mail.de` – replace `[at]` with `@`. This spelling protects the address from simple spam crawlers.
> Please include: name of the source, link, language, category, type of source and a short reason.

## Option 1: Open an issue (easy)

1. Click **Issues** at the top of the GitHub page.
2. **New issue** → choose the **“Suggest a link”** template.
3. Fill in the fields: name, link, language, category, type of source, short reason.
4. Submit. A person reviews the suggestion and adds it if it fits.

Broken link? Use the **“Broken link”** template.

## Option 2: Pull request (if you know GitHub)

1. Fork the repo and create a branch.
2. Only **one change per pull request**.
3. Add the entry to the correct `resources-<language>.md` and category.
4. Follow the format: `- **[Name](URL)** — One sentence. 📄 [Study]` (icon + English marker, no date).
5. Follow [MARKERS.md](MARKERS.md) and [AGENTS.md](AGENTS.md).
6. Briefly describe why the source should be included.

## What we do not include

Miracle cures, advertising, affiliate links, paywall-only content, conspiracy sources, URL shorteners, duplicate entries.
Details are in [AGENTS.md](AGENTS.md) and in the German [README-de.md](README-de.md).

## Conduct

Please be respectful – the [Code of Conduct](CODE_OF_CONDUCT.md) applies to issues, pull requests and all discussions.
